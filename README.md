# 내가 고친 코드 설명을 AI가 대신 써주는 도우미 만들기

## 프로젝트 개요 (Project Overview)

- Git 변경 사항 수집 및 AI API 전달, 변경 맥락 기반 커밋 메시지와 Pull Request 제목·본문 초안 생성 Python CLI 도구

## 실행 환경 (Environment)

- **언어**: Python 3.10 이상
- **외부 API**: OpenAI API
- **환경변수**: `AI_API_KEY`

## 프로젝트 구조 (Project Structure)

```text
.
├── main.py               # CLI 진입점 및 명령어 처리
├── requirements.txt      # Python 의존성 목록
├── README.md             # 프로젝트 개요 및 개발 체크리스트
└── SETUP.md              # 설치·실행 방법 및 프로젝트 시현
```

## 수행 항목 체크리스트

### Git 변경 사항 수집

- [ ] Git이 초기화된 프로젝트 루트에서 CLI 실행
- [ ] `git status` 결과를 수집해 변경된 파일 목록 확인
- [ ] `git diff` 결과를 수집해 변경 내용 확보
- [ ] 변경 사항이 없으면 안내 메시지 출력 후 종료
- [ ] Git 명령 실행 실패 시 원인을 포함한 오류 메시지 출력

### AI API 연동

- [ ] API Key를 `AI_API_KEY` 환경변수로 관리하고 코드에 하드코딩하지 않기
- [ ] Git 변경 사항을 컨텍스트로 포함해 AI API 호출
- [ ] 생성된 커밋 메시지 또는 PR 초안을 터미널에 출력
- [ ] 변경 요약을 커밋 메시지 또는 PR 초안과 함께 출력
- [ ] 네트워크 오류, 인증 실패 등 API 오류 원인 안내
- [ ] `--model`, `--temperature`, `--max-tokens` CLI 옵션 및 기본값 제공
- [ ] `commit`, `pr` 명령별 API 요청을 1회로 제한하고 호출 횟수 출력(권장)

### 커밋 메시지 자동 생성

- [ ] `commit` 명령으로 커밋 메시지 생성
- [ ] 변경 사항 요약을 기반으로 커밋 제목 1줄 출력
- [ ] 커밋 제목은 50자 이내 권장, 최대 72자로 제한
- [ ] 커밋 본문 사용 시 변경 파일 1~3개 또는 핵심 변경 사항 1~2개를 불릿으로 요약
- [ ] 생성 결과를 사용자가 복사할 수 있도록 명확한 구획으로 출력

### Pull Request 제목·본문 자동 생성

- [ ] `pr` 명령으로 PR 제목과 본문 초안 생성
- [ ] PR 제목을 1줄, 최대 80자로 제한
- [ ] PR 본문에 `Why`, `What`, `How to Test` 섹션 포함
- [ ] 각 PR 본문 섹션에 최소 1개 이상의 불릿 포함
- [ ] PR 제목과 본문을 구분해 터미널에 출력

### 출력 형식 검증 및 다듬기

- [ ] 커밋 제목 길이 규칙 검증
- [ ] PR 제목 길이 규칙 검증
- [ ] PR 필수 섹션과 섹션별 불릿 존재 여부 검증
- [ ] 규칙 위반 시 재생성 또는 후처리 수행
- [ ] 최종 출력에 헤더와 구분선을 적용해 가독성 확보

### 보안 및 안전 모드

- [ ] `--safe-mode` 옵션 제공
- [ ] 다음 안전 정책 중 1개 이상 구현
  - [ ] API Key, 이메일 등 민감정보 패턴을 마스킹한 뒤 전송
  - [ ] 전송 가능한 diff의 파일 수 또는 줄 수 제한
- [ ] 생성 결과를 사용자가 반드시 검토한 뒤 적용하도록 안내

### 보너스 과제

- [ ] 기존 프로젝트에 의미 있는 변경을 적용하고 실제 PR 1건 완성
- [ ] AI 초안과 최종 PR의 변경점을 5~10줄로 정리
- [ ] 기존 커밋/PR 스타일을 분석해 팀 컨벤션 정의
- [ ] `.ai-gitgen.yml`, `--convention`, 프롬프트 템플릿 중 하나로 컨벤션 적용
- [ ] 컨벤션 적용 전·후 생성 결과 비교
- [ ] 정규표현식 기반 마스킹 또는 diff 전송 제한 정책 고도화
- [ ] 안전 모드 ON/OFF 결과 비교

### 제약 사항 (Constraints)

- **API Key 관리**: 환경변수 전용 관리, 소스 코드·로그·Git 이력 미포함
- **AI API 요청**: 과도한 비용 방지를 위한 1회 실행당 1~2회 이내 제한
- **Git 연동 범위**: `git status`, `git diff` 기반 변경 사항 수집
- **자동화 범위**: 커밋 메시지 및 PR 초안 출력
- **원격 작업 금지**: `git push` 및 GitHub PR 생성 API 자동 실행 금지
- **사용자 검토**: AI 생성 결과 검토·수정 후 적용
- **실행 인터페이스**: 별도 웹 화면 없이 터미널 실행

### CLI 옵션

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `--model` | 구현 시 확정 | 호출할 AI 모델 |
| `--temperature` | 구현 시 확정 | 생성 결과의 다양성 조절 |
| `--max-tokens` | 구현 시 확정 | 최대 출력 토큰 수 제한 |
| `--safe-mode` | 구현 시 확정 | 민감정보 마스킹 또는 diff 전송 제한 적용 |
