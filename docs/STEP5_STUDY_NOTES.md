# 5단계 구현 후 면접/학습 개념 정리

5단계는 TTL 명령어와 만료 정책을 구현하는 단계이다. 핵심은 시간 기반 상태를 저장소에 추가하면서도, 조회와 삭제의 일관성을 유지하는 것이다.

## 1. 핵심 개념

- TTL은 key에 만료 시간을 부여하는 기능이다.
- `EXPIRE key seconds`는 현재 시각 기준으로 만료 시각을 계산한다.
- `TTL key`는 남은 시간을 Redis 스타일 정수 응답으로 반환한다.
- 만료된 키는 없는 키처럼 처리한다.
- 최소 힙은 가장 빨리 만료될 키를 찾는 데 적합하다.

## 2. lazy deletion

TTL 구현에서 모든 키를 매 순간 검사하면 비효율적이다. 그래서 실제 접근 시점이나 상태 조회 시점에 만료 여부를 정리하는 lazy deletion을 사용한다.

흐름:

```text
GET key
-> key 만료 여부 확인
-> 만료되었으면 삭제 후 (nil)
-> 아니면 값 반환
```

같은 키에 `EXPIRE`가 여러 번 호출되면 힙에는 오래된 만료 기록이 남을 수 있다. 이때 `expires` 해시맵의 최신 값과 힙에서 꺼낸 값을 비교해 오래된 기록을 무시한다.

## 3. Redis TTL 응답

- 키가 없거나 만료됨: `(integer) -2`
- 키는 있지만 만료 시간이 없음: `(integer) -1`
- 만료 시간이 있음: `(integer) N`
