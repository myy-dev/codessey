# 7단계 구현 후 면접/학습 개념 정리

7단계는 CLI REPL과 에러 처리를 통합하는 단계이다. 핵심은 사용자가 반복적으로 명령을 입력하고, 시스템이 안정적으로 파싱, 실행, 출력, 종료를 처리하도록 만드는 것이다.

## 1. 핵심 개념

- REPL은 Read, Eval, Print, Loop의 약자이다.
- CLI는 입력 루프와 명령 실행 결과 출력을 담당한다.
- 저장소 로직은 CLI에 의존하지 않아야 한다.
- 에러 응답은 일관된 형식으로 반환되어야 한다.

## 2. REPL 흐름

```text
프롬프트 출력
-> 사용자 입력 읽기
-> exit/quit 확인
-> 파싱
-> 명령 실행
-> 응답 출력
-> 반복
```

## 3. 에러 처리 구분

- 알 수 없는 명령
- 인자 개수 오류
- 정수 파싱 실패
- OOM
- 빈 입력
- 따옴표 파싱 실패

에러는 예외를 그대로 출력하지 않고 Redis 스타일 응답으로 변환한다.
