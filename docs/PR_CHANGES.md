```text
## Why
- 기본적으로 민감정보 마스킹과 전송량 제한을 적용하여 보안을 강화하기 위해
- 사용자 문서와 실제 코드 동작을 일치시키기 위해

## What
- main.py에서 --safe-mode 기본값을 False에서 True로 변경
- README.md와 USER_GUIDE.md에서 기본 옵션 설명을 OFF에서 ON으로 수정
- test_cli.py에서 안전 모드 기본값이 활성화임을 확인하는 테스트 추가 및 수정

## How to Test
- 미실행: 기본 커맨드 실행 시 --safe-mode가 활성화되어 있는지 확인
- 미실행: --no-safe-mode 옵션을 주었을 때 안전 모드가 비활성화되는지 확인
- 미실행: 문서(README.md, USER_GUIDE.md)에서 기본 안전 모드 설명이 ON으로 변경되었는지 검토

API 요청 횟수: 1
```
