# AI 초안 대비 PR 검토 본문 수정 내역

기준 초안: [실제 OpenAI PR 결과](examples/live-pr-draft.json).
최종 PR: [myy-dev/B3-2 #1](https://github.com/myy-dev/B3-2/pull/1).
아래 내용은 실제 생성 초안을 검토하여 GitHub에 게시할 때 수정한 내역이다.

1. 제목의 `docs:`를 `feat:`로 바꾸고, README/SETUP 개선에서 실행 가능한 Git 초안 CLI 구현으로 주목적을 명확히 했다.
2. Why에 문서만 있던 저장소에서 동작하는 CLI가 필요했다는 배경과 비용·민감정보 전송 범위 제한 목적을 추가했다.
3. What에 모델 입력 제한으로 빠진 staged/unstaged/untracked 수집과 명령당 API 1회 제한을 보완했다.
4. What에 커밋 72자·PR 80자 상한과 필수 섹션/불릿의 로컬 검증·보정 동작을 추가했다.
5. 안전 정책을 10파일·200줄·20,000자, 자격증명 파일·심볼릭 링크 제외 등 확인 가능한 수치와 동작으로 구체화했다.
6. `--staged`, `--base`, `--preview`, JSON 출력, 환경 설정과 팀 컨벤션을 실제 구현에 맞게 설명했다.
7. How to Test의 문서 확인 제안을 실행한 89개 테스트·94% 커버리지·린트 검사와 재현 명령으로 보완했다.
8. 실제 생성 3회 성공, 시연 입력의 200줄 제한, CLI가 커밋·push·PR 게시를 실행하지 않는다는 범위를 명시했다.
