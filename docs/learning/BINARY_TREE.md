# 이진 트리

## 기본 구조

각 노드가 왼쪽 자식과 오른쪽 자식을 최대 하나씩 갖는 트리 구조

자식이 하나만 있거나 없는 노드도 허용

## 트리 순회

| 순회 | 방문 순서 |
| --- | --- |
| 전위 순회 | 현재 노드 → 왼쪽 → 오른쪽 |
| 중위 순회 | 왼쪽 → 현재 노드 → 오른쪽 |
| 후위 순회 | 왼쪽 → 오른쪽 → 현재 노드 |
| 레벨 순회 | 위 레벨부터 왼쪽에서 오른쪽 |

전위·중위·후위 순회는 깊이 우선 탐색에 해당

레벨 순회는 너비 우선 탐색에 해당

모든 노드를 한 번씩 방문하므로 시간 복잡도는 O(n)

## 이진 탐색 트리

이진 트리에 값의 정렬 규칙을 추가한 구조(Binary Search Tree, BST)

- 현재 노드보다 작은 값: 왼쪽 하위 트리
- 현재 노드보다 큰 값: 오른쪽 하위 트리
- 중복 값 처리: 허용, 무시, 개수 저장 등 정책에 따라 결정

중위 순회 시 값을 오름차순으로 방문

### 주요 연산

- 삽입: 루트부터 값을 비교해 왼쪽 또는 오른쪽으로 이동한 뒤 빈 위치에 추가
- 검색: 찾는 값과 현재 노드를 비교하며 왼쪽 또는 오른쪽 하위 트리 탐색
- 삭제: 자식 수에 따라 연결 관계 조정

### 삭제

- 자식이 없는 노드: 해당 노드 제거
- 자식이 하나인 노드: 부모와 해당 자식을 직접 연결
- 자식이 둘인 노드: 오른쪽 하위 트리의 최솟값 또는 왼쪽 하위 트리의 최댓값으로 대체

### 시간 복잡도

삽입·검색·삭제 시간은 트리 높이 `h`에 비례하는 O(h)

- 균형 잡힌 트리: O(log n)
- 한쪽으로 치우친 트리: O(n)
- 중위 순회: O(n)
