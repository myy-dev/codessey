# Pub/Sub

## 기본 개념

| 개념 | 설명 |
| --- | --- |
| Pub/Sub (Publish/Subscribe) | 발행자와 구독자가 채널을 통해 메시지를 주고받는 방식 |
| 발행자(Publisher) | 채널에 메시지를 보내는 주체 |
| 구독자(Subscriber) | 관심 있는 채널의 메시지를 받는 주체 |
| 채널(Channel) | 메시지의 주제를 구분하는 전달 경로 |

## 메시지 전달 흐름

```text
발행자
  └─ 메시지 발행
       └─ 채널
          └─ 구독자에게 전달
```

1. 구독자가 관심 있는 채널을 구독
2. 발행자가 채널에 메시지를 발행
3. 채널이 현재 구독 중인 구독자에게 메시지를 전달

발행자는 구독자를 직접 알 필요가 없고, 구독자도 발행자를 직접 알 필요가 없음

## 메시지 큐와의 차이

| 구분 | Pub/Sub | 메시지 큐 |
| --- | --- | --- |
| 목적 | 같은 메시지의 전달 | 작업의 분배와 처리 |
| 전달 대상 | 현재 구독 중인 구독자 | 메시지를 가져간 소비자 |
| 관계 | 발행자와 구독자의 직접 연결 없음 | 생산자와 소비자의 직접 연결 없음 |
