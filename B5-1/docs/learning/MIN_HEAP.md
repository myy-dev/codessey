# 최소 힙

## 핵심 개념

힙: 부모·자식 사이의 우선순위 관계를 유지하는 완전 이진 트리

최소 힙: 부모 값이 자식 값보다 작거나 같은 구조로, 루트에서 최솟값 확인 가능

완전 이진 트리: 마지막 레벨을 제외한 모든 레벨을 채우고 마지막 레벨은 왼쪽부터 채우는 형태

완전 이진 트리이므로 노드를 배열의 연속된 위치에 저장 가능

배열의 전체 정렬이 아니라 부모가 자식보다 작거나 같은 관계만 보장

## 배열 인덱스 관계

0부터 시작하는 인덱스 `i` 기준 부모·자식 관계

- 부모 인덱스: `(i - 1) // 2`
- 왼쪽 자식 인덱스: `2 * i + 1`
- 오른쪽 자식 인덱스: `2 * i + 2`

## 주요 연산

| 연산 | 동작 | 시간 복잡도 |
| --- | --- | --- |
| 삽입 | 마지막 위치에 추가 후 부모 방향으로 이동 | O(log n) |
| 최솟값 조회 | 루트 값 확인 | O(1) |
| 최솟값 제거 | 루트를 제거하고 마지막 값을 루트로 옮긴 뒤 자식 방향으로 이동 | O(log n) |

## 최소 힙 속성 복구

삽입: 배열 마지막에 추가한 값을 부모와 비교

부모보다 작은 동안 교환하며 루트 방향 이동

삭제: 루트 보관 후 마지막 요소를 루트로 이동

더 작은 자식과 비교·교환하며 리프 방향 이동
