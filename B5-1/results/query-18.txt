Query 18
요구 사항: 보너스
확인 목적: 보너스 - 2번 고객의 주문 수를 서브쿼리 방식으로 확인한다.

실행 SQL:
SELECT c.customer_id, c.name,
       (
           SELECT COUNT(*)
           FROM orders AS o
           WHERE o.customer_id = c.customer_id
       ) AS order_count
FROM customers AS c
WHERE c.customer_id = 2;

실행 결과:
customer_id | name | order_count
------------+------+------------
2           | 이서연  | 2
