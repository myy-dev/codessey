# 화면 및 URL

## 화면과 처리 경로

| 기능 | HTTP 방식 | URL | 정상 응답 |
|---|---|---|---|
| 홈 화면 | GET | `/` | HTML 홈 화면 |
| 메모 목록 | GET | `/memos` | HTML 메모 목록 |
| 메모 등록 화면 | GET | `/memos/new` | 빈 등록 폼 |
| 메모 등록 처리 | POST | `/memos` | 저장 후 상세 화면으로 303 리다이렉트 |
| 메모 상세 | GET | `/memos/{memo_id}` | 메모 번호·제목·내용·작성일시·수정일시 |
| 메모 수정 화면 | GET | `/memos/{memo_id}/edit` | 기존 값이 포함된 수정 폼 |
| 메모 수정 처리 | POST | `/memos/{memo_id}/edit` | 수정 후 상세 화면으로 303 리다이렉트 |
| 메모 삭제 처리 | POST | `/memos/{memo_id}/delete` | 삭제 후 목록 화면으로 303 리다이렉트 |

## 검색

```text
GET /memos?q=FastAPI
```

검색어의 앞뒤 공백을 제거하며, 빈 검색어는 전체 목록을 반환한다. 목록은 작성일시 내림차순이며 작성일시가 같으면 메모 번호 내림차순으로 정렬한다.

## 오류 응답

| 상황 | HTTP 상태 | 응답 |
|---|---|---|
| 등록·수정 입력값 검증 실패 | 422 | 입력값과 오류 안내가 포함된 HTML 폼 |
| 존재하지 않는 메모 조회·수정·삭제 | 404 | 메모를 찾을 수 없다는 HTML 안내 화면 |
| 정수로 해석할 수 없거나 SQLite 정수 범위를 벗어난 메모 번호 | 404 | 메모를 찾을 수 없다는 HTML 안내 화면 |
| 등록되지 않은 주소 | 404 | 페이지를 찾을 수 없다는 HTML 안내 화면 |
