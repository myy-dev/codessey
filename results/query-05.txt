Query 05
확인 목적: 주문과 고객 정보를 INNER JOIN으로 연결해 주문자를 확인한다.

실행 SQL:
SELECT o.order_id, c.name, c.city, o.order_date, o.status
FROM orders AS o
INNER JOIN customers AS c
    ON o.customer_id = c.customer_id
ORDER BY o.order_date ASC, o.order_id ASC;
